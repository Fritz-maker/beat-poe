# Wordfight (the LÖVE original)

This is the desktop game that Beat Poe! grew out of, written in Lua for the
[LÖVE](https://love2d.org) engine. It has the original four monsters
(Gutter Gnome, Mildew Wraith, Ink-Blot Troll, Dictionary Dragon) and the same
rules, kept here as the origin story and as a working desktop game.

## Run it

Install LÖVE (`sudo apt install love` on Ubuntu), then from this folder:

    ./run.sh

The script copies the two word lists from `../data/` on first run (they are
shared with the web game, so they are not stored here twice) and starts LÖVE.

`README-original.md` is the original README with the controls and tuning notes.
